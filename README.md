# Tetris Game

I heard C++ is a great language to learn/reinforce fundamentals so I decided to make a Tetris game with it.

## Try out the game!

>[!NOTE]
Only available on MacOS for now.

Download the release file [here](https://github.com/coleridge113/Tetris/releases/download/v1.0.0/tetris-ios-arm64.zip)

Once downloaded:
1. Go to the directory where the zip file is
2. Open your terminal
3. Run this command: `xattr -d com.apple.quarantine ./game`
4. Lastly, run this command: `./game`
